# DCF 估值工具集

一个纯本地运行的单文件 HTML 估值工具，浏览器打开即用，**不上传任何数据**。

在线预览：<https://lonelydancer88.github.io/dcf-valuation-tool/>

## 三个标签

1. **自定义现金流 + 永续** —— 逐年手填自由现金流（可增删行），末段用 Gordon 永续；输出企业价值、股权价值、每股内在价值，附逐年折现明细与图表。
2. **老唐估值法** —— 填第三年自由现金流，PE 固定 **25 / 30** 两档对照，给出三年后合理估值、理想买点（×50%）、一年内卖点（×150%）与「低估 / 持有 / 高估」状态。
3. **两阶段固定增长** —— 基期 FCFF + 高增长期 + 永续增长，含 WACC×g₂ 双因素敏感性热力图。

## 主要功能

- **股票速填**：输入名称或代码，自动带入股数与当前股价（内置腾讯、茅台、五粮液等预设，可「存为预设」扩充）。
- **实时获取**：按代码联网取当前汇率、现价与总股本（行情：腾讯 `qt.gtimg.cn`；汇率：`open.er-api.com`）。接口不可用时可用内置快照手填。
- **港股模式**：股价按港元计价，结果同时给出**人民币**与**港元**两套；比价口径随之切换，避免跨币种误比。
- **实时重算**：任意参数改动即时更新结果卡片、折现表、柱状图与敏感性热力图。
- **方法说明**：两个用到 WACC / 永续增长率的标签内附可折叠的取值说明。

## 使用

下载 `index.html` 双击用浏览器打开即可，或直接访问上面的在线地址。无构建、无依赖、可离线（实时获取需联网）。

## 自测

`test_dcf.js` 用 [jsdom](https://github.com/jsdom/jsdom) 对页面做端到端测试（加载页面、模拟输入与点击、断言渲染结果）：

```bash
npm install jsdom
node test_dcf.js
```
